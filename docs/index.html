RSRB · RackStation ReBoot

Debian 12 instead of DSM on the Synology RS812 – with its own kernel, a web UI and this package repository.

Debian 12 statt DSM auf der Synology RS812 – mit eigenem Kernel, Weboberfläche und dieser Paketquelle.

Install the OSOS installieren RackPanel GitHub

1 · Add the repository

1 · Paketquelle einrichten

curl -fsSL https://syntax-xxx.github.io/rsrb/setup.sh | sudo sh

2 · Install packages

2 · Pakete installieren

sudo apt install rackpanel rsrb-neofetch rsrb-release

Works on any Debian/Ubuntu with systemd: armel (RS812), armhf, arm64 and amd64. Updates arrive with apt upgrade.

Läuft auf jedem Debian/Ubuntu mit systemd: armel (RS812), armhf, arm64 und amd64. Updates kommen mit apt upgrade.

Packages

Pakete

rackpanel

The NAS web UI: storage, SMART, RAID, files, SMB/NFS shares, users, apps, updates, API. Asks for user and password during install.

Die NAS-Weboberfläche: Speicher, SMART, RAID, Dateien, SMB/NFS-Freigaben, Benutzer, Apps, Updates, API. Fragt bei der Installation nach Benutzer und Passwort.

rsrb-neofetch

neofetch with the RSRB logo and NAS info (volumes, IP, web UI). Also adds rsrbfetch.

neofetch mit RSRB-Logo und NAS-Infos (Volumes, IP, Weboberfläche). Dazu der Befehl rsrbfetch.

rsrb-release

Brands the system as RSRB (os-release, login banner, login message). Debian's files come back when you remove it.

Macht das System zu RSRB (os-release, Anmeldebanner, Login-Meldung). Beim Entfernen kommen Debians Dateien zurück.

Manual setup

Von Hand einrichten

Key and source list, if you prefer not to pipe a script into a shell:

Schlüssel und Quelle, falls du kein Skript in die Shell leiten willst:

sudo curl -fsSLo /usr/share/keyrings/rsrb.gpg https://syntax-xxx.github.io/rsrb/rsrb.gpg
echo "deb [signed-by=/usr/share/keyrings/rsrb.gpg] https://syntax-xxx.github.io/rsrb stable main" | sudo tee /etc/apt/sources.list.d/rsrb.list
